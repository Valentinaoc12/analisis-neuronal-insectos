- # Taller 2 - De la neurona a la figura

Este repositorio contiene el notebook desarrollado para el Taller 2, donde se analizaron registros extracelulares obtenidos con una sonda de 16 electrodos.

## Contenido

El análisis incluye:

- lectura de archivos HDF5
- filtrado pasa-banda de 300–5000 Hz
- detección de potenciales de acción
- extracción de características de las formas de onda
- agrupamiento con K-means
- evaluación y curación de unidades
- autocorrelogramas y correlogramas cruzados
- raster plots y PSTH
- análisis estadístico con Z-score, t-test y bootstrap
- figura final de resultados

## Datos
